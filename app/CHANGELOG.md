# 변경 내역

## [1.0.2] - 2026-11-28

카카오톡으로 주소를 보낼 때 미리보기가 뜨게 했어요. 1.0.1 에서 바로 올려도 돼요 (저장 파일은 그대로예요).

### 더한 것

- 카카오톡 · 메신저에 주소를 보내면 미리보기 그림과 소개 글이 떠요 (og). 방 입장 링크(`?room=방번호`)는 ‘My Pick 방에 들어오세요’로 뜨고, 방 제목은 넣지 않아요. 그림 주소에는 `.env` 의 `SITE_URL` 을 쓰니 정식 주소를 꼭 넣어 주세요. 그림은 `npm run og` 로 다시 만들 수 있어요

## [1.0.1] - 2026-11-27

100명 · 1000명(방 5개 · 방마다 관리자 5명 + 공동 진행자) 모의 진행에서 찾은 것을 고쳤어요.

### 고친 것

- 큰 화면: 선택지가 많으면(6개부터) 결과가 화면 아래로 넘쳐 선택지가 잘리고, 내려 보면 주제 제목이 가려지던 것 → 두 줄 · 세 줄로 나눠 30개까지 한 화면에 다 보여요
- 큰 화면: 방이 끝난 뒤의 ‘최종 결과’ 도 주제가 많으면 아래로 넘치던 것 → 주제 한 줄 · 결과 한 줄로, 5개부터 두 줄 · 11개부터 세 줄로 나눠요
- ‘동점 가리기’ 를 두 번 누르거나 여러 진행자가 동시에 누르면 같은 주제가 누른 만큼 생기던 것 → 하나만 (이미 있으면 알려 줘요)
- 픽이 열려 있는 동안에는 백업을 새로 만들거나 내려받을 수 없어요: 저장 파일에는 마감 전 숫자가 들어 있어서, 최고 관리자가 진행 중에 받아 가면 결과를 미리 볼 수 있었어요 (연습 · 리허설 · 실시간 공개 방은 빼고)
- 관리자 ‘한눈에’: 잠깐 멈춘 주제에 ‘잠깐 멈춤’ 표시
- 지켜보기 기록: 시간을 얼마나 늘렸는지 · 멈출 때 남은 시간이 보여요
- 화면을 한 번도 누르지 않은 기기에서 진동을 부르다 브라우저 경고가 남던 것
- 같은 접속 주소(학교 한 곳)에서 몇 명이 방 번호 · 코드를 틀리면 그곳 전체가 60초 동안 못 들어오던 것 → 틀린 횟수를 기기마다 따로 세고(기기 표시 쿠키), 시간이 지나면 잊어요. 결과 확인도 같이 막히던 것 포함
- 방장 · 공동 진행자 로그인도 같아요: 그 방에 한 번 들어왔던 기기는 남이 일부러 틀려도 잠기지 않아요
- 실시간 연결을 얻지 못한 화면(자리가 다 찼거나 막힌 망)은 4초마다 직접 읽어 멈추지 않아요
- 관리자 로그인: 한 번 제대로 로그인한 기기는, 같은 곳의 다른 사람이 비밀번호를 일부러 틀려도 잠기지 않아요
- 서버가 진행 중에 다시 켜졌을 때: 아직 다시 붙지 못한 사람을 빼고 ‘모두 픽함’ 으로 일찍 마감하던 것 → 1분 기다려요. 관리자 · 방장 로그인도 그대로 이어져요 (서버가 신호를 받고 바로 꺼지게 고쳐 다시 켜지는 시간도 짧아졌어요)
- 날마다 뜨는 백업도 픽이 열려 있는 동안에는 미뤄요 (마감 전 숫자가 백업에 담기지 않게)
- 동시에 받을 실시간 연결 기본값 2000 → 5000, 거의 차면 관리자 ‘한눈에’ 에 알림
- 비밀번호 있는 방에 한꺼번에 들어올 때 느리던 것 (맞는 비밀번호는 한 번만 무겁게 계산)
- 제목 · 선택지에서 글자 방향을 뒤집는 문자를 빼요
- 방 만들기: 방 번호로 입장하는 방은 한 사람이 여러 번 픽할 수 있다는 안내
- 이용약관 · 개인정보 처리방침을 1.0.1 에 맞게 고쳤어요 (시행일 2026-11-27): 기기 표시 쿠키, 관리자가 로그인한 기기의 표시와 서버가 다시 켜질 때의 로그인 표시를 저장한다는 것, 주제가 열려 있는 동안 받은 픽 · 백업을 볼 수 없다는 것, 방 번호 · 코드를 마구 넣는 일 금지, 간편 방식 방은 여러 번 참여할 수 있다는 것. ‘최근에 바뀐 점’ 을 두 문서에 적었어요
- 좁은 휴대폰(320 폭): 기관 이름이 길면 안내 페이지의 위쪽 줄이 옆으로 8px 넘치던 것 → 이름을 말줄임해요

### 더한 것

- 끝내는 버튼이 더 잘 보여요: 관리자 화면의 ‘지금 마감’ 을 결과 아래에서 남은 시간 바로 아래로 올리고 붉게 · 크게, 리모컨의 ‘지금 마감’ 도 붉게. ‘방 끝내기’ 는 설정 탭에만 있던 것을 어느 탭에서나 보이게 하고(주제가 열려 있는 동안에는 숨겨요), 리모컨에도 남은 주제가 없을 때 나와요
- 맨 아래 칸을 새로 짰어요 (PC · 안내 페이지): 흰 카드 하나에 My Pick 한 줄 소개와 ‘하틸리티가 만든 상자’ 칩 · 함께하기 · 알아보기. 하틸리티 메인 사이트 · 그려봄과 같은 짜임이고 색 · 둥글기는 My Pick 것 그대로예요. 휴대폰에서는 링크만 몇 줄로 줄여 보여 주고, 휴대폰 참여 화면(`/m`)은 예전의 작은 줄 그대로예요
- 모의 진행 시험을 저장소에 넣었어요 (도커를 켠 뒤): `npm run drill`(100명 · 거의 모든 기능) · `drill:1000`(방 5개 · 관리자 여럿이 동시에) · `drill:2000`(무작위 사용자, 뒤에 씨앗 숫자) · `drill:attack`(공격 59가지, 내 컴퓨터의 개발 서버에만) · `drill:screen`(큰 화면에 선택지 · 주제가 많을 때). 공격 시험 바로 뒤에는 접속 주소가 1분 잠기니 조금 있다가 다른 시험을 돌려요

## [0.2.0] - 2026-11-26

담당 선생님 의견(“더 직관적으로”)을 반영하고, 기록을 더 단단하게 했어요.

### 더한 것 · 바꾼 것

- 끝난 방의 ‘최종 결과’: 큰 화면 · 참여자 화면 · 참관인 화면에서 모든 안건의 결과를 한눈에
- ‘PC 화면으로 보기’ / ‘휴대폰 · 태블릿 화면으로 보기’ (고른 것을 기억해요), 가로로 눕힌 휴대폰 · 태블릿 화면 대응
- 참관인 화면의 기록에는 관리자 계정 이름 대신 ‘운영자’로 나와요
- 깃허브 올리기: `깃허브 맞추기.command` · `깃허브/My-Pick/README.md`
- 소개 페이지(`/about`), 태블릿 배치를 700px 부터(세로로 든 태블릿도), 태블릿 첫 화면은 그림과 들어가기 칸을 나란히
- 소개 페이지 꾸밈: 그림이 있는 머리, 세 가지 약속, 흐름 3단계, 만든 까닭, 만든 사람 · 방식, 고쳐 쓰기 안내. 태블릿 옆 칸의 방 번호가 두 줄로 잘리던 것 고침
- 더 직관적으로(담당 선생님 의견): 딱딱한 낱말을 쉬운 말로 (안건→주제, 가결 · 부결→통과 · 통과 못 함, 과반→절반을 넘으면, 정족수→최소 참여 인원, 기권→건너뛰기, 회의록→결과 정리, 참관인→지켜보는 사람, 이의→확인 요청, 결선→동점 가리기, 금칙어→막을 낱말)
- 방 만들기(방장) · 주제 넣기 칸을 ‘기본 + 더 자세히 정하기’로 나눔. 접혀 있어도 지금 값은 한 줄로 보여요. 방 만들기 전 설명은 굵은 한 줄 + 짧은 풀이로, 픽 카드 · 기다림 · 픽 완료 화면에 ‘지금 할 일’ 한 문장
- 기록을 더 단단하게: `.env` 의 `AUDIT_SECRET` 을 넣으면 기록을 열쇠로 봉해요(HMAC). 저장 파일 · 백업만 가진 사람은 고친 뒤 해시를 다시 맞출 수 없어요. 이미 쌓인 기록은 `node server.mjs --rekey-audit` 로 한 번 다시 봉해요
- 기록 지문: 기록 화면 · 지켜보기 화면에 지금 지문을 보여 주고, 적어 둔 지문을 넣으면 그때까지의 기록이 잘리거나 다시 쓰이지 않았는지 알려 줘요
- 결과 확인(`/verify`)이 숫자뿐 아니라 그 마감이 기록에 남아 있는지도 함께 봐요
- 도장 그림을 동그라미 안의 체크 표시로 (첫 화면 그림 · 픽 카드 · 결과 · 파비콘 모두)
- 휴대폰 · 태블릿 다듬기: 태블릿에서는 ‘픽하기’ 버튼이 픽 카드 안(고르는 곳 바로 아래)에, 휴대폰에서 막 마감된 뒤에는 방금 결과가 기다림 칸 바로 아래에, 지켜보기 화면의 숫자 칸을 고르게 · 윗줄이 접히지 않게, 진행 화면의 방 번호가 두 줄로 잘리지 않게
- 결과 정리 인쇄물에 기록 지문, 안내 페이지 ‘참여하기’를 세 칸으로, 화면을 읽어 주는 프로그램에 ‘30초 · 10초 남았어요’와 ‘가장 많이 받음’을 알려 줘요
- 화면 점검(`npm run audit`)을 태블릿(820) · 작은 휴대폰(320) 너비까지 (화면 92개)
- 글 고침: ‘0명 픽 상자’ → ‘0명이 픽했어요’, ‘연습 픽’로 → 으로 등
- 입장 코드는 한 번만 (엄격 방식): 이미 쓴 코드를 다른 기기에서 넣으면 들어올 수 없어요 (전에는 들어오면서 앞 기기를 끊었어요). 진행자가 종이 코드를 확인하고 ‘다시 열기’를 해 주면 한 번 더 들어올 수 있고, 들어오면 다시 닫혀요. 픽은 그대로 한 번뿐
- 진행 화면 정리: ‘큰 화면에 띄울 것’을 접어 두고(지금 값은 한 줄로 보여요), 결과 내려받기 · 결과 인쇄 · 결과 정리 인쇄를 ‘결과 남기기’ 하나로, 안내 글을 짧게. 휴대폰에서 주제 목록이 첫 화면에 보여요
- 긴 글 대응: 제목이 길면 글자를 줄이고(큰 화면 · 픽 카드 · 지켜보기), 긴 설명은 두 줄 + ‘설명 더 보기’, 휴대폰 머리줄의 방 이름은 두 줄까지, 리모컨 제목은 세 줄까지, 지켜보기 기록은 두 줄까지
- 지켜보기 화면에 ‘큰 화면 모드’ (빔프로젝터 · TV 용: 글자를 키우고 화면을 가득 채워요. 고른 것을 기억해요)
- 화면 점검이 받을 수 있는 만큼 꽉 채운 글(띄어쓰기 없는 글 포함)과 결과 화면까지 봐요 (화면 112개)
- 조용한 손들기: 참여자가 ‘질문 있어요 · 더 설명해 주세요’를 익명으로 알리고, 진행자는 몇 명인지만 봐요. 주제가 열리거나 ‘손 내리기’를 누르면 내려가고, 어디에도 저장하지 않아요
- 결과 그림 받기: 마감된 주제의 결과를 그림 한 장(PNG)으로 (결과 확인 코드 포함, 브라우저 안에서만 만들어요)
- 참여율 알림: 큰 화면에 ‘아직 N명 남았어요’
- 쉬운 말 모드 (방 설정): 참여 화면의 글자를 키우고 문장을 짧게
- 이용약관 · 개인정보 처리방침을 오늘 바뀐 것에 맞춰 고침 (시행일 2026-11-26)
- 오류 제보(`/feedback`): 누구나 오류 · 바라는 점을 보내고, 관리자 ‘신고’ 화면에 모여요. 이름 · 연락처 · 접속 주소는 받지 않고, 한 시간에 다섯 번까지
- 잠깐 멈추기: 열린 주제의 남은 시간을 얼리고 그동안 픽을 받지 않아요 (설명을 더 할 때). 다시 시작하면 남은 시간부터. 진행 화면 · 리모컨에 단추, 참여 화면 · 큰 화면에 ‘잠깐 멈췄어요’
- 화면 꺼짐 막기: 방에 들어와 있는 동안, 그리고 큰 화면을 띄워 둔 동안 화면이 저절로 꺼지지 않아요 (지원하는 브라우저에서, HTTPS 일 때)

- 불러오는 틀, ‘보내는 중’ 표시, 긴 목록은 나눠 보기, Pretendard 글꼴을 사이트 안에 (필요한 조각만)
- 휴대폰 리모컨 보강: 진행자 메모, 방금 끝난 결과 · 결선 · 다시, 안건 목록에서 골라 열기, 입장 QR, 공지 띄우기, 1분 더
- 참관인 화면 보강: 넓은 화면 두 칸, 남은 시간 · 참여 점 · 진행 상황, 전체 화면
- 없는 주소 · 열 수 없는 화면 · 끝난 방에 ‘첫 화면으로’
- 화면 점검 `npm run audit` (넘침 · 잘린 글자 · 작은 글씨 · 누르기 작은 곳 · 이름 없는 버튼)

- 누르기 작은 곳(바닥 링크 · 체크 상자 · 접는 제목)을 44px 이상으로, 휴대폰에서 관리자 메뉴가 화면 밖으로 밀리던 것
